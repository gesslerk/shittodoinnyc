# Sources

Grouped by research lane. Each line is `Name | URL | why it matters`. The research pass fetches these pages directly and searches beyond them. If a page moves or dies, fix the URL here; the engine also falls back to web search when a fetch fails.

Mainstream listicle sources (Time Out, Secret NYC, the viral-list accounts) are deliberately absent. Eater and The Infatuation are included only for openings and one-night collaborations, never for "best of" lists.
